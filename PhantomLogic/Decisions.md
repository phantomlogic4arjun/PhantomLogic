# Architecture and Business Decision Log

This document records important decisions made by Autonomous Software Labs.

## Decision 001 — Local-First AI

Status: Accepted

Use Ollama to run local AI models wherever practical.

Reason: Privacy, cost control, and independence from external AI services.

## Decision 002 — Coding Agent

Status: Accepted

Use OpenCode as the primary AI coding environment.

Reason: Agent-oriented coding capabilities and local Ollama integration.

## Decision 003 — Workflow Automation

Status: Accepted

Use n8n for workflow automation.

Reason: Visual workflow management and integration capabilities.

## Decision 004 — Initial Technology Stack

Status: Accepted

- React + TypeScript + Vite
- Python + FastAPI
- SQLite
- Git

Reason: Lightweight, maintainable, and suitable for local development.

## Decision 005 — First Product

Status: Accepted

Build a personal finance tracker.

Initial scope:
- Income tracking.
- Expense tracking.
- Categories and budgets.
- Monthly financial summaries.
- Charts and reports.
- CSV import.
- Local data storage.

Reason: Establish a complete product development and delivery process.
